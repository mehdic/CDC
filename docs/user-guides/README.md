# User Guides

Complete guides for each user role in MetaPharm Connect.

## User Role Overview

MetaPharm Connect serves five distinct user roles with customized interfaces and workflows:

### 1. Patients
**Primary Focus**: Manage prescriptions, health records, and order medications

- [Patient Guide](./patient.md) - Complete patient user guide
- **Key Features**: Prescription tracking, medication orders, teleconsultation, health records
- **Target Users**: Individual patients seeking healthcare services

### 2. Pharmacists
**Primary Focus**: Prescription processing, inventory management, patient care

- [Pharmacist Guide](./pharmacist.md) - Complete pharmacist user guide
- **Key Features**: Prescription validation, inventory management, patient communication, analytics
- **Target Users**: Licensed pharmacists managing pharmacy operations

### 3. Doctors
**Primary Focus**: Create prescriptions, monitor patients, communicate with healthcare team

- [Doctor Guide](./doctor.md) - Complete doctor user guide
- **Key Features**: Prescription writing, patient records, interprofessional communication
- **Target Users**: Licensed physicians managing patient care

### 4. Nurses
**Primary Focus**: Medication ordering, patient monitoring, delivery coordination

- [Nurse Guide](./nurse.md) - Complete nurse user guide
- **Key Features**: Medication ordering, patient tracking, delivery management
- **Target Users**: Healthcare nurses coordinating patient care

### 5. Delivery Personnel
**Primary Focus**: Manage deliveries, route optimization, QR code scanning

- [Delivery Guide](./delivery.md) - Complete delivery personnel guide
- **Key Features**: Delivery assignment, GPS tracking, QR scanning, route optimization
- **Target Users**: Logistics personnel handling pharmacy deliveries

## Creating an Account

### New User Registration

1. **Go to** MetaPharm Connect login page
2. **Click** "Create Account"
3. **Select Your Role**: Patient, Pharmacist, Doctor, Nurse, or Delivery Personnel
4. **Enter Personal Information**:
   - Email address
   - Full name
   - Phone number
   - Date of birth
5. **Professional Information** (if applicable):
   - License number
   - Pharmacy/Facility name
   - Professional credentials
6. **Accept Terms** of Service and Privacy Policy
7. **Click** "Create Account"
8. **Verify Email** - Check email for verification link
9. **Set Password** - Choose a strong password
10. **Two-Factor Authentication** - Enable MFA (recommended for professionals)

### Verification Process

**For Patients**:
- Email verification required
- Identity verification (optional, for sensitive features)

**For Healthcare Professionals**:
- Email verification required
- Professional license verification (can take 24-48 hours)
- Swiss cantonal registry validation
- Approval before full access

## Login & Authentication

### Basic Login

1. **Go to** MetaPharm Connect login page
2. **Enter Email Address**
3. **Enter Password**
4. **Click** "Login"

### Two-Factor Authentication (2FA)

If enabled, you'll be prompted:

1. **Enter One-Time Code** from authenticator app or SMS
2. **Click** "Verify"

**Setting Up 2FA**:
- Go to Settings → Security
- Click "Enable Two-Factor Authentication"
- Scan QR code with authenticator app (Google Authenticator, Authy, etc.)
- Enter verification code
- Save backup codes in secure location

### Forgot Password

1. **Click** "Forgot Password" on login page
2. **Enter Email Address**
3. **Check Email** for password reset link
4. **Click Link** in email (expires in 24 hours)
5. **Enter New Password**
6. **Click** "Reset Password"
7. **Login** with new password

## Managing Your Profile

### Update Profile Information

1. **Click** Profile icon (top right)
2. **Click** "My Profile"
3. **Edit Information**:
   - Name
   - Phone number
   - Email address
   - Profile photo
   - Specialty (for professionals)
4. **Click** "Save Changes"

### Profile Visibility

**For Patients**:
- Profile is private by default
- Healthcare professionals can only see information they need

**For Professionals**:
- Limited public profile showing name and credentials
- Patients can verify your credentials

## Security Settings

### Change Password

1. **Go to** Settings → Security
2. **Click** "Change Password"
3. **Enter Current Password**
4. **Enter New Password** (minimum 12 characters)
5. **Confirm New Password**
6. **Click** "Update Password"

### Login Activity

**View Recent Logins**:
1. **Go to** Settings → Security
2. **View** "Recent Activity"
3. **See** IP address, device, location, timestamp
4. **Click** "Sign Out" next to suspicious activity

### Connected Devices

**Manage Devices**:
1. **Go to** Settings → Devices
2. **View** All connected devices
3. **Click** "Sign Out" to disconnect device
4. **Add Device** by scanning QR code or entering code

## Messaging

### Send a Message

1. **Click** Messages icon
2. **Click** "New Message" or select user
3. **Type** your message
4. **Click** "Send"
5. **Message appears** in conversation thread

### Manage Conversations

- **Archive**: Swipe left or right-click → Archive
- **Mute**: Conversation → Mute notifications
- **Search**: Use search bar to find conversations
- **Pin**: Mark important conversations as pinned

### Message Features

- **File Sharing**: Click attachment icon to share documents
- **Mentions**: Type @name to mention someone
- **Reactions**: React to messages with emoji
- **Read Receipts**: See when message was read

## Notifications

### Notification Settings

1. **Go to** Settings → Notifications
2. **Toggle Categories** on/off:
   - Messages
   - Prescriptions
   - Deliveries
   - Appointments
   - System alerts
3. **Set Quiet Hours**: When to mute notifications
4. **Choose Delivery**: Email, SMS, push notification

### Notification Center

**Access Notifications**:
1. **Click** Bell icon (top bar)
2. **View** Recent notifications
3. **Click** notification to view details
4. **Mark as Read** or dismiss

## Teleconsultation

### Starting a Call

1. **Click** on contact or conversation
2. **Click** Phone or Video icon
3. **User receives** call notification
4. **When answered**, call begins
5. **Use controls** to mute/unmute, share screen, end call

### During Call

- **Mute/Unmute**: Control audio input
- **Start/Stop Video**: Toggle video on/off
- **Share Screen**: Share your screen for demonstrations
- **Record**: Record consultation (with consent)
- **End Call**: Click "End Call" button

## Privacy & Compliance

### Your Data Rights

MetaPharm Connect complies with:
- **GDPR** (General Data Protection Regulation)
- **HIPAA** (Health Insurance Portability and Accountability Act)
- **Swiss Data Protection Laws**

### Your Privacy Controls

1. **Go to** Settings → Privacy
2. **Control Who Can**:
   - View your profile
   - Contact you
   - Access your health records
   - See your activity status
3. **Download Your Data** - Request personal data export
4. **Delete Account** - Permanently delete account and data

### Data Encryption

- All communications are encrypted end-to-end
- Medical records encrypted at rest
- Secure connections (HTTPS/TLS)
