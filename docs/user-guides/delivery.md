## Getting Started

### Account Setup

1. **Sign Up** with employer-provided credentials
2. **Identity Verification**:
   - Provide government-issued ID
   - Background check (required for controlled substances)
   - Driver's license verification
   - Vehicle registration (if applicable)
3. **Profile Setup**:
   - Full name
   - Phone number
   - Emergency contact
   - Vehicle information
   - Delivery zones
4. **Mobile App Installation**:
   - Download MetaPharm Connect Delivery app
   - iOS or Android
   - Enable GPS location services
   - Enable notifications
   - Allow camera access (for QR scanning)

### Your Role

As delivery personnel, you are responsible for:

- ✅ Receiving delivery assignments from pharmacy

- ✅ Handling special requirements (cold chain, controlled substances)
- ✅ Obtaining proof of delivery (signature, photo)
- ✅ Communicating delivery status in real-time
- ✅ Maintaining professional service standards

## Starting Your Shift

### Shift Activation

**Step-by-Step**:

1. **Open** MetaPharm Connect Delivery app
2. **Click** "Start Shift"
3. **Scan** Your employee badge or enter code
4. **Verify** Vehicle information
5. **Enable** GPS location sharing
6. **Review** Today's deliveries
7. **Status** changes to "Available"

**Pre-Shift Checklist**:
- ✅ Vehicle fueled and ready
- ✅ Phone fully charged
- ✅ Delivery bags/coolers prepared
- ✅ Signature pad working
- ✅ Camera functional
- ✅ ID badge visible
- ✅ GPS enabled

### Receiving Delivery Assignments

**Assignment Process**:

1. **Pharmacy** prepares medication packages
2. **System** assigns deliveries to you based on:
   - Your current location
   - Delivery zone
   - Package special requirements
   - Route optimization
   - Your availability
3. **You receive** Notification with assignment details
4. **Review** Delivery list:
   - Patient names
   - Addresses
   - Special handling notes
   - Priority levels
5. **Accept** Assignment
6. **Navigate** to pharmacy for pickup

## Delivery Workflow

### Step 1: Package Pickup

**At the Pharmacy**:

1. **Arrive** at pharmacy
2. **Click** "At Pharmacy" in app
3. **Scan** Each package QR code:
   - Camera opens automatically
   - Align QR code in frame
   - Scan confirms package assignment
4. **Verify** Package information:
   - Patient name
   - Address
   - Special handling requirements
   - Package count
5. **Load** Packages in vehicle:
   - Cold chain items in cooler
   - Fragile items secured
   - Controlled substances in locked compartment
6. **Confirm** "All Packages Loaded"
7. **Start** Delivery route

**Package Information Displayed**:
- Package ID
- Patient name (first name + last initial for privacy)
- Delivery address
- Special requirements icons:
  - ❄️ Cold chain (keep refrigerated)
  - 🔒 Controlled substance (signature + ID required)
  - 📦 Fragile
  - ⚡ Priority/Urgent
- Delivery time window
- Patient contact number

### Step 2: Navigation to Patient

**Route Optimization**:

1. **App displays** Optimized route
2. **AI considers**:
   - Traffic conditions
   - Patient availability windows
   - Cold chain priorities (deliver first)
   - Controlled substance security
   - Distance efficiency
3. **Follow** Turn-by-turn navigation
4. **Update** Automatically shared:
   - Current location
   - Estimated arrival time (ETA)
   - Patient receives real-time updates

**En Route Features**:
- Live traffic updates
- Automatic ETA recalculation
- Patient notifications (arriving in 10 min, 5 min)
- Pharmacy can see your location
- Call patient button (if needed)

### Step 3: Delivery to Patient

**At Patient Location**:

1. **Arrive** at delivery address
2. **Click** "Arrived" button
3. **Patient** receives arrival notification
4. **Ring** doorbell or knock
5. **Verify** Patient identity:
   - Confirm name
   - Check ID for controlled substances
6. **Scan** Package QR code again to confirm delivery
7. **Hand** Package to patient
8. **Obtain** Proof of delivery (see section below)
9. **Collect** Any returns (expired medications for disposal)
10. **Click** "Delivery Complete"
11. **Move** to next delivery

**Patient Communication**:
- Be courteous and professional
- Explain medication storage requirements
- Answer basic questions (pharmacy contact for medical questions)
- Ensure patient understands special handling
- Provide pharmacy phone number if questions

## Route Optimization

### AI-Powered Route Planning

**How It Works**:

The system automatically creates the most efficient route considering:

**Priority Factors**:
1. **Cold Chain Items** - Delivered first (time-sensitive)
2. **Patient Availability** - Preferred delivery windows
3. **Controlled Substances** - Security considerations
4. **Distance** - Shortest total distance
5. **Traffic** - Real-time traffic conditions
6. **Urgency** - Priority/emergency orders first

**Route Display**:
- Map view with all delivery locations
- Numbered sequence (1, 2, 3...)
- Color coding:
  - 🔴 Red = Priority/Emergency
  - 🟠 Orange = Time-sensitive (cold chain)
  - 🟢 Green = Standard
- Estimated time for each stop
- Total estimated completion time

### Manual Route Adjustment

**If You Need to Change Order**:

1. **Click** "Edit Route"
2. **Drag** Deliveries to reorder
3. **App warns** if change affects:
   - Cold chain timing
   - Patient availability
   - Priority orders
4. **Confirm** Change
5. **System** recalculates ETAs
6. **Patients** notified of updated ETAs

**When to Adjust**:
- Patient calls requesting different time
- Traffic makes original order inefficient
- Patient not home, need to skip and return
- Pharmacy adds urgent delivery mid-route

## QR Code Scanning

### Package Tracking with QR Codes

**QR Code Locations**:
- Each package has unique QR code
- Code contains encrypted package information
- Links package to patient and order

**Scanning Process**:

1. **At Pickup**: Scan to confirm you received package
2. **At Delivery**: Scan to confirm delivery to patient
3. **At Return**: Scan if returning package to pharmacy

**Scanning Tips**:
- Ensure good lighting
- Hold phone steady
- Align code in frame
- Wait for beep/vibration confirmation
- Code turns green when scanned successfully

**If QR Code Won't Scan**:
1. Clean camera lens
2. Adjust lighting/angle
3. Enter package ID manually
4. Take photo of package
5. Report issue in app
6. Complete delivery and document

### Traceability Benefits

**QR Code System Tracks**:
- Pickup timestamp
- Pickup person (you)
- Delivery timestamp
- Delivery location (GPS)
- Recipient confirmation
- Complete chain of custody

**Compliance**:
- Required for controlled substances
- Audit trail for all packages
- Proof of delivery
- Insurance/payment verification

## Special Handling Requirements

### Cold Chain Items ❄️

**Requirements**:
- Must remain refrigerated (2-8°C)
- Use insulated cooler bag
- Include ice packs
- Monitor temperature
- Deliver within 2 hours of pickup

**Delivery Process**:
1. Verify cold chain icon on package
2. Place in cooler immediately at pickup
3. Deliver first on route (highest priority)
4. Inform patient of storage requirements
5. Ensure patient refrigerates immediately
6. Document temperature maintenance

**If Temperature Compromised**:
- Do not deliver
- Return to pharmacy immediately
- Report issue in app
- Pharmacy determines if medication still safe

### Controlled Substances 🔒

**Legal Requirements**:
- Patient signature REQUIRED
- Photo ID verification REQUIRED
- Only hand to patient (not family/neighbors)
- Secure locked storage in vehicle
- No overnight storage

**Delivery Process**:
1. Verify controlled substance icon
2. Store in locked compartment
3. Confirm patient identity with photo ID
4. Match name on ID to order
5. Obtain signature on device
6. Photograph ID (app does this automatically)
7. Complete delivery confirmation
8. If patient unavailable, return to pharmacy (cannot leave)

**Security**:
- Never leave in unattended vehicle
- Do not discuss contents
- Keep locked until delivery
- Report any loss immediately

### Fragile Items 📦

**Handling**:
- Pack securely to prevent breakage
- Keep upright
- Do not stack heavy items on top
- Handle with care
- Inform patient about contents

### Priority/Urgent Deliveries ⚡

**Requirements**:
- Deliver within specified timeframe
- Patient waiting for medication
- May require direct route (skip optimization)
- Confirm delivery immediately in app
- Contact patient if delayed

## Proof of Delivery

### Signature Collection

**Electronic Signature**:

1. **Click** "Get Signature"
2. **Hand** Device to patient
3. **Patient** Signs on screen with finger/stylus
4. **Verify** Signature clear and readable
5. **Save** Signature (automatic)
6. **Timestamp** Recorded automatically

**Signature Required For**:
- All controlled substances
- High-value medications
- Insurance requirements
- Special request deliveries

### Photo Proof

**When to Take Photo**:
- Patient requests contactless delivery
- Package left at door (with patient permission)
- No signature required
- Additional proof needed

**Photo Process**:
1. **Click** "Take Photo"
2. **Photograph** Package at delivery location
3. **Include** Door/building number in frame
4. **Ensure** Clear, well-lit image
5. **Save** Photo (automatic upload)
6. **Timestamp** and GPS recorded

### Alternative Proof Methods

**Voice Confirmation**:
- Patient can verbally confirm receipt
- You record confirmation in app
- Include patient name and time

**SMS Confirmation**:
- System sends SMS to patient
- Patient replies to confirm receipt
- Confirmation logged automatically

## Failed Deliveries

### Common Failure Reasons

**Patient Not Home**:
- Most common reason
- Patient didn't respond to door
- No one available to receive

**Wrong Address**:
- GPS location incorrect
- Address doesn't exist
- Patient moved

**Patient Refused**:
- Doesn't recognize order
- Not expecting delivery
- Package damaged

**Access Issues**:
- Building locked/secured
- Gate code not working
- Cannot locate address

### Failed Delivery Process

**Step-by-Step**:

1. **Attempt** Delivery (ring doorbell, knock, call patient)
2. **Wait** 5 minutes
3. **If no response**:
   - Click "Delivery Failed"
   - Select failure reason
   - Add detailed notes
   - Take photo of location
4. **System automatically**:
   - Notifies patient
   - Notifies pharmacy
   - Notifies nurse (if nursing order)
5. **Options**:
   - **Reschedule**: Patient chooses new time
   - **Return to Pharmacy**: You bring package back
   - **Contact Patient**: Pharmacy calls patient
   - **Leave Safe Location**: With patient permission only

**Documentation Required**:
- Reason for failure
- Time of attempt
- Photo of location
- Any contact with patient/neighbors
- Next steps taken

### Rescheduling Failed Deliveries

**Patient Reschedules**:
1. Patient receives notification
2. Patient selects new delivery time
3. You receive updated assignment
4. Return for reattempt

**Same-Day Reattempt**:
- If patient responds quickly
- You're still in area
- Add to current route
- System adjusts route automatically

**Return to Pharmacy**:
- If cannot reschedule today
- Controlled substances (cannot keep overnight)
- Cold chain items approaching time limit
- Scan package on return
- Document reason

## Troubleshooting

### Common Issues

**"GPS not working"**:
- Enable location services in phone settings
- Ensure app has location permissions
- Restart app
- Check internet connection
- Contact support if persists

**"QR code won't scan"**:
- Clean camera lens
- Improve lighting
- Try different angle
- Enter package ID manually
- Report damaged code

**"Cannot find address"**:
- Verify address in app
- Use map view
- Call patient for clarification
- Check building/apartment numbers
- Report incorrect address

**"Patient not answering"**:
- Ring doorbell multiple times
- Knock loudly
- Call patient phone number
- Wait 5 minutes
- Follow failed delivery process

**"App crashed/froze"**:
- Force close and reopen app
- Check internet connection
- Clear app cache
- Restart phone
- Contact support

**"Package missing from pharmacy"**:
- Verify you have correct pharmacy location
- Check with pharmacy staff
- Review assignment in app
- Report discrepancy
- Wait for pharmacy confirmation
